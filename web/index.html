nada deterministic MIDI from a small JSON recipe

Same recipe, same file, every time. Everything runs locally in your browser; nothing is uploaded.

Preview uses simple synth tones; instruments are approximate. The exported .mid carries the real General MIDI instrument numbers.

Recipe format 
{
  "title": "my song",
  "tempo": 120,
  "time_signature": [4, 4],
  "tracks": [
    {"name": "melody", "instrument": "Music Box",
     "notes": [{"note": "C4", "start": 0, "duration": 1},
               {"chord": ["E4", "G4"], "start": 1, "duration": 0.5}]},
    {"name": "drums", "drums": true,
     "notes": [{"note": "kick", "start": 0, "duration": 0.25}]}
  ]
}

Times are in beats. Notes: C4, F#3, Bb5 (C4 = middle C) or 0-127. Drums: kick, snare, closed hihat, open hihat, crash, ride, clap, low/mid/high tom, rimshot, cowbell, tambourine, pedal hihat.
